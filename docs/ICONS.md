# Memoryz 채워진 아이콘

2026-09-15. 홈, 학습, 시간표, 커뮤니티, 마이와 하위 화면의 73개 아이콘 이름을 `src/components/icons.tsx`로 통일했다. 기존 아웃라인 라이브러리 의존성과 화면별 선 두께·빈 채움 조절을 제거했다.

## 관찰한 레퍼런스

- [토스 홈 · Mobbin](https://mobbin.com/screens/44c0d237-000a-4dac-8b60-c9b19b80366a): 채워진 하단 탭, 중립색 비활성 아이콘, 짙은 활성 아이콘, 작은 내부 구멍으로 구분하는 형태.
- [토스 메뉴 · Mobbin](https://mobbin.com/screens/59ac3ea2-4b35-4fe1-988e-7d0694ebea3d): 알림·설정·문서·편집을 단순한 면으로 표현하고, 화살표와 같은 조작 기호는 작은 크기로 유지.
- [토스 전체 서비스 · Mobbin](https://mobbin.com/screens/9a252e16-e2bd-4665-bb00-a7ffa1e53d9b): 아이콘과 제목의 간격, 하단 탭의 형태와 색상 계층.

실제 SVG는 [Phosphor Icons core](https://github.com/phosphor-icons/core) 2.1.1의 MIT 리소스다. 토스의 시각 구조를 참고한 별도의 아이콘 구성으로, 토스 원본 에셋을 사용한 것은 아니다. MIT 고지는 `public/licenses/phosphor-icons.txt`에 보관한다. [전체 아이콘 보기](icons.html), [매핑 원본](icon-mapping.json).

## 구현 기준

- 의미를 가진 사물 아이콘은 fill 변형을 사용한다. 집, 책, 달력, 대화, 사람, 종, 폴더, 문서, 잠금, 카메라 등이 해당한다. 서술형 코칭은 면이 넓은 노트, 오답노트는 채워진 체크리스트로 구분한다.
- 화살표·체크·닫기·검색·추가·이동 같은 조작 기호는 둥근 bold 경로를 사용한다. 이들 역시 `stroke` 없이 채워진 SVG 경로로 렌더링한다.
- 시간표의 날짜·시간 입력도 같은 채움형 달력·시계로 표시한다. 실제 입력은 네이티브 date/time을 유지하며, 기본 표시만 바꾸고 선택기를 여는 영역은 그대로 둔다.
- 모든 아이콘은 256×256 뷰박스, `fill=currentColor`, `stroke=none`이다. 공통 컴포넌트 타입에서 외부 fill/stroke 덮어쓰기를 제외했다.
- 하단 탭은 26px 프레임, 본문은 기존 20–24px 프레임을 따른다. 탭 비활성 아이콘은 중립 회색, 활성 아이콘은 짙은 글자색이다. 버튼의 터치 영역과 레이블을 유지했다.
- 주황 배경에서는 흰색 콘텐츠를 상속한다. 흰색 버튼 위의 주황색 화살표처럼 별도 배경이 있는 요소는 해당 배경 기준 색상을 따른다.
- 공감과 저장 아이콘은 항상 채워져 있다. 공감 여부는 목록의 색상과 상세 버튼의 `aria-pressed` 및 배경으로, 저장 여부는 버튼 상태와 문구로 구분한다.
- 장식 아이콘은 스크린리더에서 숨기며, 버튼은 기존 접근성 이름을 유지한다. 단독 의미가 필요할 때는 아이콘에 `aria-label`을 제공할 수 있다.
- 필요한 72개 SVG만 로컬 코드에 포함했다. 외부 아이콘 다운로드나 별도 아이콘 런타임 패키지가 필요하지 않다.

## 추가 (2026-09-15, 자료 뷰어)

`Minus`(축소)와 `DownloadSimple`(파일 저장)을 같은 둥근 bold 경로 규칙으로 추가했다. 자료 뷰어의 확대·축소와 파일 저장 버튼이 쓴다.

## 검증 범위

컴포넌트 18개 파일의 아이콘 참조와 전체 73개 이름을 대조했다. 교육용 인과 화살표도 공통 기호로 교체했다. 앱 로고·PWA 설치 아이콘과 사용자가 올린 학습 이미지는 UI 조작 아이콘 교체 범위에 포함하지 않는다.

프로덕션 빌드 및 타입 검사를 통과했다. 실제 모바일 브라우저의 5개 탭과 과목 상세·업로드·시간표 추가·게시물 상태·설정 화면을 확인했다. 390px 및 360px에서 가로 넘침이 없었으며, 모든 관찰 화면에서 공통 아이콘 밖의 SVG와 잘못된 fill/stroke가 없었다. [11개 캡처 갤러리](screenshots/icons/index.html), [DOM 검사](screenshots/icons/browser-audit.json), [원본 아이콘 보드](icons.html)에 근거를 기록했다.

날짜 선택기를 열고 닫았으며, 시간은 저장 전 초안에서 09:20으로 입력하고 네이티브 선택기 열기·닫기를 확인했다. AX로 시간 선택기를 조작하던 중 한 브라우저 탭이 종료됐다. 새 탭에서 좌표 클릭으로 선택기와 입력을 다시 확인했고, 최종 탭의 콘솔 오류는 없었다. 실제 iOS/Android 기기 검증은 포함하지 않는다.

프로필·커뮤니티·시간표 데이터 변경, 카드 평가, 외부 AI 호출 없이 표시와 탐색 동작을 확인했다. 학부모·관리자 화면은 공통 소스의 적용 및 빌드 확인 범위이며, 역할을 바꿔 브라우저에서 재검증하지 않았다.

추가 요청에 따라 홈·로그인·로딩 화면의 워드마크를 모두 `memoryz.`로 통일했다. 기존 글꼴·굵기·색상은 유지했다. 재빌드 후 로그인·로딩 화면에서 마침표 표시를 확인했다. [최종 로고 캡처](screenshots/wordmark.png). 아이콘 갤러리의 홈 캡처는 마침표 추가 전 아이콘 검증 시점의 화면이다.
