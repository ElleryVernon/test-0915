# Memoryz 디자인 디테일 개선 · 2026-09-15

> 이전 수정 기록입니다. 사용자 교정에 따라 짙은 글자·뱃지 삭제 방향을 철회했습니다. 현재 적용 결과는 [흰 텍스트와 뱃지 복원](DESIGN_CORRECTION.md)을 참고하세요.

사용자가 지적한 그라데이션 위 가독성과 장식적인 틴트 뱃지를 중심으로 수정했다. 기존 주황·크림 곡선 아트워크와 모바일 정보 밀도는 유지했다.

## 변경

- 그라데이션의 흰 글자와 그림자를 짙은 브라운 글자로 변경. 홈, 정답 카드, 생성 중 안내, 마이, 응원, 로그인에 같은 기준을 적용했다.
- 홈 복습 버튼은 짙은 단색, 높이 44px로 조정했다. 진행률은 24개 장식 조각 대신 실제 완료 비율을 표시하는 막대와 접근성 값으로 변경했다.
- 홈 연속 학습일은 배경 없는 텍스트로, 중복된 ‘4단계’ 뱃지는 설명에 통합했다. 프로필 아바타, 과목별 문제 수, 카드 유형, 학부모 역할 표시의 배경 장식을 줄였다.
- 기억 배지 상세는 반복되는 그라데이션 카드 대신 아이콘·설명·획득 상태를 표시하는 목록으로 정리했다.
- 주요 버튼과 날짜 선택은 짙은 단색으로 통일했다. 하단 메뉴의 중복 장식선을 제거하고 활성 글자색을 진하게 조정했다.
- 학부모 `/parent-boards` 화면에서 `/parent` 메뉴까지 함께 활성화되던 경로 비교를 수정했다. `/`로 진입한 학부모 홈도 자녀 현황 메뉴가 선택된다.
- 에러·오프라인 등 의미가 있는 상태 표현은 유지했다.

## 검증 근거

SVG의 모든 색에서 RGB 각 채널 최솟값을 취한 보수적 배경색은 `#ff7d24`다. 이 색에 대해 sRGB 상대휘도 공식으로 계산한 대비는 주요 글자 `#30251f` **5.82:1**, 보조 글자 `#4b3425` **4.52:1**이다. 흰 글자는 같은 배경에서도 2.56:1이며 크림 영역에서는 더 낮아진다. 흰 배경 위 공통 보조 글자 `#6b7684`는 **4.62:1**이다. 이 수치는 해당 색 조합의 대비이며 제품 전체의 접근성 인증을 뜻하지 않는다.

프로덕션 빌드에서 홈·정답 보기·학습·카드 목록·마이·기억 배지·시간표·학부모 화면을 실제 브라우저로 확인했다. 홈은 360/390/430px에서 문서 너비와 뷰포트 너비를 비교했다. 복습 버튼 높이 44px, 진행률 4/14와 실제 막대 비율, 날짜 선택의 활성 상태를 확인했다. UI 점검 중 복습 평가나 AI 생성 등 데이터 변경은 실행하지 않았다.
