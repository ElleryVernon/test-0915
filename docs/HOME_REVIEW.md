# 홈 리뷰 적용

2026-09-15 · 사용자가 제공한 `Memoryz 홈 리뷰.html`의 기본 To-Be(neutral)를 적용했다. 디자인 문서의 예시 수치를 복사하지 않고 현재 계정의 실제 기록과 연결했다.

| 리뷰 항목 | 반영한 동작 |
| --- | --- |
| 1. 두 층 헤더 | 로고 네비 44px, `memoryz.` 22px, 개인 이름·연속 학습 일수로 구성한 24px 인사말. 검색·알림·프로필은 44px 터치 영역 유지. |
| 2. 중복 스트릭 | 별도 배지와 하단 일주일 섹션을 합쳤다. 헤딩 아래 16px 점 7개와 이번 주 학습 일수, 마이 이동을 제공한다. 서울 시간 월–일 기준으로 계산하며 지난주 기록을 이번 주에 포함하지 않는다. |
| 3. 복습 카드 대비 | #F3F3F3 카드의 숫자·설명은 중립색. 주황 #FF6F0F는 52px 전폭 CTA와 진행 막대에 사용한다. CTA 콘텐츠는 흰색, 16px/700. 오늘·어제 카드 복습 건수는 서버 기록에서 가져온다. |
| 4. 다음 일정 | 시작 시각·진행 여부·소요 시간·오늘 완료 수를 표시한다. 지난 미완료 일정이 남으면 모두 완료로 표시하지 않는다. 긴 제목만 줄이고 소요 시간은 보존한다. |
| 5. 실제 이어하기 | 마지막으로 학습한 미완료 자료 한 건, 저장한 서술형 초안 한 건, 현재 오답을 표시한다. 자료의 이미 푼 문제는 제외하고 남은 문제로 시작한다. 서술형 단계·키워드·순서·힌트·작성 답안은 계정별 로컬 초안으로 복원한다. 전체 기능은 학습 탭 링크로 연결한다. |
| 6. 밀도·위계 | 홈 섹션 제목 17px/700, 위 여백 20px. 행 최소 64px(두 줄 콘텐츠 실제 66px), 24px 아이콘·12px 간격. 회색 띠 제거. 하단 탭은 44px 터치 영역·24px 아이콘과 실제 기기 safe-area를 사용한다. |
| 7. 응원 | 실제 발신자의 닉네임과 도착 시각을 제목에 표시한다. 메시지와 포인트·흰색 알약형 고마워요 버튼으로 단순화했다. 전송 중/전송 완료 상태를 구분한다. |
| 8. 최근 자료 | 최신 자료 두 건, 과목·생성된 문제·서술형 수·업로드 경과 시간을 표시한다. 0개 표기는 생략하고 해당 자료 상세 시트를 바로 연다. |
| 9. 온보딩 프로모 | 자료가 없는 경우에만 첫 자료 업로드 안내를 표시한다. 기존 사용자의 홈 마지막에는 기존 체험 공간 안내만 남긴다. |

## 데이터와 적용 범위

- 카드 모델에 자료 ID가 없으므로 자료별 카드 수를 추정하지 않았다. 자료에 연결된 문제·서술형 수를 보여준다.
- 서술형 초안은 현재 브라우저에 계정별로 보관한다. 다른 기기로 동기화되지는 않는다. 채점 완료, 삭제된 문제, 내용이 바뀐 문제, 손상된 초안은 이어하기에서 제외한다. 저장소 접근이 거부되어도 학습을 중단시키지 않는다.
- 인사말·일정·복습량·응원·자료명은 실제 값이다. 문서에 있는 `12일째`, `12/20`, `500P` 같은 예시 값을 넣지 않았다.
- 문서의 가짜 상태바·배터리·홈 인디케이터는 구현하지 않았다. 브라우저와 OS가 제공하는 영역을 사용한다.
- 일반 본문/다른 화면의 행 크기는 유지했다. 공통 하단 탭의 아이콘·높이 변경은 홈·학습·시간표·커뮤니티·마이에서 확인했다.

## 검증

`npm run build` 성공. `npx tsx --test tests/home.test.ts tests/study.test.ts` 19개 통과, 실패 0. 서울 자정/주간 경계, 지난 일정, 중복 답안의 진도 계산, 빈 상태, 자료 링크, 계정별 초안 복원·삭제·손상 처리를 확인했다.

실제 Codex 앱 브라우저에서:

- 390×844와 360×800 홈을 확인했다. 헤더 44px, 가로 넘침 없음, 복습 CTA·일정·첫 이어하기가 하단 탭 위에 들어온다.
- 10장 복습 시작 → 1/10 카드, 문제 1/7 자료 이어하기 → 남은 6문제의 1/6 화면을 확인했다. 답안 제출/카드 평가는 하지 않았다.
- 최근 자료 → 해당 제목의 자료 상세 시트를 확인했다.
- 서술형에서 검증용 키워드 하나 선택 → 페이지를 떠남 → 홈에 1단계/키워드 1개 표시 → 재진입 후 선택 복원을 확인했다. 검증 후 해당 선택을 해제해 원래 상태로 되돌렸다.
- 주간 기록 → 마이, 전체 학습 → 학습, 일정 → 시간표, 공통 커뮤니티 탭 이동을 확인했다.
- 빈 홈은 동일 HomeScreen을 렌더한 별도의 **검증용 fixture**로 390px/360px에서 확인했다. 실제 계정 데이터를 삭제하거나 바꾸지 않았다. 빈 상태의 실제 API 동작을 검증한 것은 아니다.
- 응원 전송, AI 생성·채점 호출, 일정 저장은 하지 않았다. 실제 iOS/Android 기기 검증은 포함하지 않는다.
