# 커뮤니티 탐색 개편

## 반영한 흐름

- 커뮤니티 제목을 전체 커뮤니티, 학교 커뮤니티, 쪽지의 URL 기반 상단 탐색으로 변경했다. 선택한 공간은 중립 색상과 밑줄로 표시한다.
- 기존 종이비행기 진입점은 사람 아이콘으로 교체하고 `/community/me`를 연결했다. 내가 쓴 글, 내가 댓글 남긴 글, 저장한 글과 프로필·학교 수정 경로를 제공한다. 학부모 경로는 `/parent-boards`를 사용한다.
- 학교 게시판의 작성·조회·댓글·공감·저장은 서버의 등록 학교 범위를 따른다. 학교가 없으면 등록 안내를 제공하며 글 작성은 서버에서도 거절한다. 학교명은 프로필의 자기 등록 값이며 재학 인증을 의미하지 않는다.
- 기존 글은 전체 커뮤니티에 유지한다. 내 활동은 조회 제한 전에 서버에서 필터링하며, 익명으로 쓴 내 글도 작성자 식별 정보를 공개하지 않고 포함한다.
- 쪽지함은 실제 대화의 최근 내용과 시간을 표시한다. 새 쪽지에서 닉네임으로 상대를 선택한다. 기존 차단·계정 접근 검사는 유지한다. 대화의 뒤로가기는 진입 맥락과 검색어를 복원하고, 대화 목록 버튼은 명시적으로 목록을 연다.
- 공통 페이지 여백·헤더 높이·간격 토큰을 사용하고 상단 버튼은 최소 44px 터치 영역을 갖는다.

## 검증

- 프런트엔드 전체 테스트, 타입 검사, 정적 빌드 및 압축 성공.
- Go 전체 테스트·빌드 및 sqlc 생성 결과 일치 확인. 학교 간 접근 차단, 학교 삭제 후 기존 학교 글 접근 차단, 익명 내 글, 저장 글, 실제 최근 대화, 차단 대상 제외를 격리된 임시 DB에서 검증했다.
- 로컬 브라우저 390px/320px에서 상단 탐색, 학교 전용 빈 상태, 학교명이 명시된 글쓰기 창, 쪽지 상대 검색·대화 진입·뒤로가기 검색어 복원, 내정보·내 글·브라우저 뒤로가기를 확인했다.
- 로컬 전용 DB의 7번 추가 마이그레이션과 로컬 서버에 반영했다. 브라우저에서 게시글이나 쪽지는 전송하지 않았다. 운영 배포 및 실제 사용자 간 송수신 검증은 이 변경의 완료 근거에 포함하지 않는다.

## 학교 정보 위치와 검색 후속 수정

- 게시글 검색은 상단 내정보 버튼 바로 왼쪽으로 복구했다.
- 학교 탭 전용 설명 행을 없애고 공통 정렬 행 왼쪽에 학교명을 표시한다. 전체 탭은 같은 자리에 ‘모든 학교’를 표시한다. 학교명을 누르면 전체 학교명·이용 범위·학교 정보 수정 경로를 시트에서 확인한다.
- 추천 콘텐츠는 게시판 필터 아래로 옮겨 추천 유무가 필터 위치를 바꾸지 않게 했다.
- 390px 실측: 두 탭 모두 게시판 필터 y=64, 정렬 행 y=128, 목록 영역 시작 y=181. 320px에서도 세 탭·검색·내정보가 모두 노출되고 가로 넘침이 없다. 검색 입력창과 학교 정보 시트 열기/닫기를 브라우저에서 확인했다.
- 레이아웃·내비게이션 검사 24개, 타입 검사, 정적 빌드 통과.
