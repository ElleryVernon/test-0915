# 사용자 여정과 학습 상호작용 점검

2026-09-16 · 로컬 Go API + Next 정적 빌드 · 학생 체험 공간 · 실제 브라우저 조작

## 판정 범위

라우트가 열리고 테스트가 통과하는 것만으로 서비스 UX를 통과 처리하지 않는다. 아래에는 직접 재현한 문제와 수정 후 조작 결과만 기록한다. 전체 문항의 교육적 타당성, 운영 배포, 외부 로그인, 학부모·관리자 여정 전체를 검증했다는 뜻이 아니다.

## 기능 동작

| 여정 | 발견한 문제 | 변경 및 직접 확인 |
| --- | --- | --- |
| 서술형 키워드 | 필요한 개수보다 많이 고를 수 있고 안내와 동작이 불일치 | 8개 중 4개를 명시하고 4개 선택 시 나머지만 비활성화. 다섯 번째 클릭으로 개수가 늘지 않음. 오답 포함 제출은 다음 단계로 넘어가지 않음. 선택한 오답을 해제하고 정답으로 교체 가능 |
| 순서 연결 | 드래그·위아래 화살표로 반복 이동. 현재 위치의 정답 여부가 먼저 드러남 | 빈 번호 칸에 누른 순서대로 추가. 선택지 위치 고정. 중복 선택 금지. 마지막 선택 취소·처음부터·특정 위치부터 다시 선택 제공. 두 번째 오답 수정 시 첫 번째 유지. 완성 전 확인 비활성화. 오답 제출은 그대로 머물며 수정 위치 안내 |
| 서술형 단계 | 이전 단계 복귀가 어렵고 화면 이탈과 단계 이동이 혼재 | 브라우저 및 화면 뒤로 가기는 이전 단계로 이동. 키워드·순서·작성 답안 유지. 답안 작성 뒤 힌트 왕복 및 새로고침에서 87자 답안 보존 확인 |
| 답안 채점 | 클릭과 처리 결과까지 확인 필요 | 실제 답안 제출 직후 입력과 버튼 잠금 및 진행 문구 표시. 서버 AI 채점 결과 100점, 포함 키워드 4/4, 입력한 87자 답안과 구체적 코칭 및 근거 표시 확인 |
| 객관식 | 풀이 세션과 선택 값이 자식 화면 왕복 시 사라질 수 있음 | 문제 ID 목록·진행·선택·응답 보존. 실제 5문제 세션에서 정답 2개·오답 3개(모르겠어요 포함)가 결과 2/5와 일치. 제출 전 선택 새로고침 복원, 첫 문제 오답 결과 → 배운 과목 설정 → 같은 1/5 오답 결과 복귀 → 2/5 진행 확인 |
| 카드 | 복습 진입·작성 중 복귀를 구분하지 않음 | 카드 뒤집기·평가 선택 화면 확인, 브라우저 뒤로 가기는 카드 목록으로 복귀. 새 카드 앞뒷면 입력 후 뒤로·앞으로 이동 시 초안 보존 확인 |

객관식 해설의 기존 ‘배운 것/지금/다음’ 카드에서 `future`에 들어 있던 틀린 선택지 문장이 후속 학습처럼 노출되는 것을 실제 발견했다. 이 안내를 제거하고 원래 질문·내 오답 선택·정답·해설을 함께 표시했다. 수정 후 네 번째와 다섯 번째 문제에서 질문과 선택 내용, 결과 집계를 확인했다.

완료 뒤 단계 히스토리가 남아 주소만 바뀌고 화면이 남는 추가 결함도 실제 발견했다. 채점 완료 시 단계 레이어를 정리하도록 수정하고, 답안 단계 새로고침 → 실제 채점 → 브라우저 뒤로 목록 → 화면 뒤로 학습까지 다시 실행해 확인했다.

## 화면 이동과 맥락

| 여정 | 발견한 문제 | 변경 및 직접 확인 |
| --- | --- | --- |
| 학습 → 검색 → 뒤로 | 홈을 새로 push하여 검색 화면이 다시 등장 | 실제 방문 이력으로 복귀. 검색어 ‘세포’와 결과를 보존 |
| 검색 → 자료 | 검색한 자료가 아닌 과목 화면만 열림 | 선택 자료 ID를 URL에 전달하여 해당 자료 시트 표시 |
| 자료 → 원본 → 뒤로 | 시트가 닫히기 전에 페이지 전체 이탈 | 원본만 닫고 자료 시트 유지. 시트 닫기 후 검색 목록으로 복귀 |
| 마이 → 복습 설정 → 저장 | 진입점과 무관하게 카드 복습으로 이동 | ‘복습 방식 저장’ 후 마이로 복귀. 동일 설정 저장의 성공 표시와 스크롤 132.5px 복원 확인 |
| 마이 → 알림/배운 과목 | 고정된 다른 페이지로 복귀 | 실제 마이 화면으로 복귀 |
| 커뮤니티 목록 → 상세 | 상세 URL이 없고 목록 필터 초기화 | post 쿼리에 상세 표시. 공부팁 필터 보존. 뒤로·앞으로·상세 새로고침 후 복귀 확인 |
| 시간표 → 일정 추가 → 시간 선택 | 중첩 선택창이 브라우저 이력과 무관 | 브라우저 뒤로는 시간 선택창만 닫음. ‘UX 확인용 초안’, 선택한 17일, 16:00–17:00 유지. 일정 추가 닫기도 날짜 유지 |
| 직접 설정 URL 진입 | 뒤로가 외부/빈 이력으로 이탈 가능 | 새 탭 /settings/learning → 화면 뒤로 → /profile 안전 복귀 |

문제가 0개인 자료에서 ‘문제 만들기’를 누르면 선택한 자료가 미리 선택된 생성 창이 열림을 확인했다. 같은 생성 동작이 중복되던 ‘문제 더 만들기’는 기존 문제가 있을 때만 표시한다. 생성 제출은 이번 여정 검증에서 실행하지 않았다.

390×844 모바일에서 선택·순서 화면과 시간표를 확인했고 시간표의 문서 가로폭 390px로 가로 넘침이 없었다. 1280×900 데스크톱에서 기존 중앙 정렬 앱 폭과 시간표 날짜·카드 배치를 확인했다. 주 메뉴로 학습을 갔다 시간표를 다시 눌러도 17일 선택이 유지되었다.

## 구현과 회귀 방지

- `JourneyHistory`: 화면 방문, 작은 화면 상태, 스크롤, 중첩 레이어를 한 곳에서 관리한다. 기존 프레임워크 history state를 보존한다. 내부 Back과 새 경로 push를 구분한다.
- 검색·커뮤니티 필터·시간표 날짜·작성 텍스트·풀이 세션은 사용자 및 방문 단위로 보존한다. 주 메뉴 재방문도 해당 탭 맥락을 복원한다.
- 선택 제한과 순서 편집은 독립 함수로 분리하여 연속 선택·오답·중복·불완전 답안·복구된 초안을 검증한다.
- 순서는 AI 출제 계약의 원인→결과 순서를 기준으로 유지했다. 출제된 모든 문항에 유일한 인과 순서가 성립하는지는 이번 화면 검증의 결론에 포함하지 않는다.

## 데이터와 환경 경계

체험 공간에서 객관식 답안 및 서술형 답안을 제출했다. 복습 설정은 기존 값으로 저장했다. 일정과 카드 검증용 텍스트는 저장하지 않았다. 게시글·메시지를 보내거나 자료를 삭제하지 않았다. 이 결과는 로컬 서비스 결과이며 운영 배포 검증이 아니다. 이미지 파일 자체는 새로고침 시 보존 대상이 아니며 작성 텍스트만 복원한다.

실행 검사와 최종 수동 판정은 `.unlazy/ux-journey/GATES.md`에 기록한다.
