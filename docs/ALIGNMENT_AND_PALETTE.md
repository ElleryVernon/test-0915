# Memoryz 공통 정렬과 팔레트

2026-09-15. 현재 기능별 개선은 [FEATURE_EVOLUTION.md](FEATURE_EVOLUTION.md)를 따른다. 주요 버튼은 후속 요청에 따라 밝은 주황으로 바뀌었다. 후속 수정으로 주황 면 전체를 단색 #FF6F0F로 통일하고 그 위 텍스트·아이콘은 흰색으로 고정한다. 중립색 뱃지와 OS 불꽃 이모지는 유지한다.

## Mobbin에서 확인한 당근의 색상 활용

- [동네생활 피드](https://mobbin.com/screens/48dce847-ee5f-4b83-8aff-ffa62f5ecb83): 주황은 글쓰기·알림, 선택된 탭은 짙은 무채색, 일반 필터는 옅은 회색으로 구분한다.
- [인기 피드](https://mobbin.com/screens/f17119e3-3712-4109-8207-efb660c1988f): 키워드 칩과 내용 구획은 중립색을 쓰고 추가 행동은 주황 버튼으로 강조한다.
- [상품 상세](https://mobbin.com/screens/4d31eaba-8aaa-4c05-bf51-c8b68df6a5a1), [거래 상세 하단 행동](https://mobbin.com/screens/d3957433-b3c2-4609-855a-98b8d5adf91e): 정보·보조 행동은 회색 계층으로, 핵심 행동은 주황으로 구분한다.
- [나의 당근](https://mobbin.com/screens/88d51219-1be1-4b5f-90fe-868e5ffc46fa): 메뉴의 선 아이콘, 본문, 화살표가 각각 같은 열을 공유한다.

아래 값은 이 활용 방식을 참고해 정한 Memoryz 팔레트다. 당근 공식 토큰을 추출한 값으로 주장하지 않는다.

## 팔레트와 역할

| 역할 | 값 | 사용 |
| --- | --- | --- |
| 브랜드 / 주요 행동 | `#FF6F0F` | 시작·저장·올리기·전송, 알림 점, 활동 표시 |
| 작은 주황 텍스트 | `#C94D09` | 흰색 복습 버튼의 글자, 작은 링크 |
| 눌림 / 호버 | `#EE6500` | 주요 버튼 상호작용 |
| 본문 | `#212124` | 제목, 일반 내용, 선택 상태, 활성 탐색 |
| 보조 | `#525257` | 아이콘 보조 정보, 뱃지 글자 |
| 설명 | `#69696E` | 설명, 날짜, 안내 |
| 메타데이터 | `#767678` | 작은 부가 정보 |
| 비활성 | `#A5A5A8` | 비활성 상태, 화살표 |
| 중립 면 | `#F3F3F3` | 뱃지, 입력, 보조 버튼 |
| 옅은 면 | `#FAFAFA` | 보조 영역, 빈 상태 |
| 구분선 | `#EDEDED` | 행 경계, 구획 |
| 강한 경계 | `#D6D6D8` | 미선택 컨트롤 경계 |
| 오류 | `#C73D32` | 실패·검증 메시지 |

주요 버튼은 사용자가 선택한 당근의 밝은 주황으로 통일한다. 흰색/#FF6F0F의 단색 대비는 약 2.79:1이므로 이 조합이 일반 텍스트 WCAG AA 4.5:1을 충족한다고 주장하지 않는다. 작은 주황 텍스트용 #C94D09, 설명색과 메타데이터의 별도 역할은 유지한다.

복습·기록·응원·생성 진행 등 기존 그라데이션 면은 primary-surface로 바꿔 단색 #FF6F0F와 --on-primary: #FFF를 사용한다. 완료 체크 역시 흰색이다. 뱃지에는 색상 틴트를 추가하지 않는다. 필터·탭의 선택은 짙은 중립색으로 구분한다. 오류·오프라인 안내의 상태 배경은 별도 의미색이다.

## 정렬 규칙

- 화면 좌우 여백: `--page-gutter: 20px`. 화면 내용, 헤더, 시트, 가로 스크롤의 시작·끝을 같은 변수로 연결한다.
- 공통 목록: 아이콘 24px + 간격 12px + 유동 본문 + 뱃지/화살표. 390px 화면에서 본문 시작 x=56px, 끝의 화살표 오른쪽 x=370px.
- 행 구분선: 본문 시작점부터 행 오른쪽 끝까지. 본문 너비나 뱃지 유무에 의존하는 음수 보정을 없앤다.
- 행 높이: 한 줄 메뉴 최소 64px, 설명이 있는 메뉴 최소 80px. 긴 내용은 자연스럽게 높이가 늘어난다.
- 기본 간격: 4/8/12/16/20/24/32px. 홈 복습 카드의 헤더·본문·진행률/설명은 독립된 grid 행으로 배치한다.
- 일반 아이콘 터치 영역: 44px. 하단 탐색 아이콘은 24px, 레이블은 16px 줄높이, 간격 4px.
- 모서리: 일반 컨트롤 12px, 중간 패널 20px, 주요 프라이머리 카드 24px. 뱃지·선택 칩의 둥근 형태는 유지한다.

## 구현 및 증거

색상의 원본은 `src/app/globals.css`의 `:root`, Tailwind 연결은 `@theme inline`이다. 컴포넌트의 하드코딩된 중립색을 `text-ink`, `text-muted`, `bg-surface`, `border-line` 등 역할 이름으로 치환했다. 공통 목록 구조는 `src/components/ui.tsx`의 `ListRow`에서 관리한다.
