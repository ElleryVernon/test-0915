Vocabulary의 위젯 크기 선택 화면과 Nibble의 게임형 진행 화면은 카드 탐색과 목적이 달라 직접 적용하지 않았다. 카드 수나 학습 상태를 가상의 점수·완료율로 바꾸지 않는다.

## 기획
- 보관함과 과목 카드 탭에 동일 CardLibrary를 사용한다. 과목에서는 범위가 고정되며 카드 목록·검색·미리보기·관리·생성을 그 자리에서 제공한다. 집중 복습을 시작할 때만 복습 화면으로 이동한다.
- 오늘 복습 요약은 선택 과목 전체의 실제 due 카드 수이며 검색 필터와 독립적이다. 전체/오늘 복습/암기완료는 목록 범위다. 검색 및 기억 상태는 범위와 교집합이며 결과 수를 별도로 표시한다.
- 기존 분포 막대는 오늘 복습 분모와 전체 카드 분모가 섞여 보이므로 보관함에서 제거한다. 전체 수와 목록 상태를 직접 읽을 수 있게 한다.
- 정렬은 복습 예정순(영구 암기완료는 마지막), 이름순. 동률은 한국어 숫자 포함 이름순, id순. 목록에는 질문을 우선하고 과목·유형·기억 상태를 보조 정보로 둔다. 오늘 그룹 내 '지금' 반복 표기는 제거한다.
- 미리보기에서 정답은 펼쳐 확인한다. 정답 확인만으로 복습 평가를 기록하지 않는다. 수정/휴지통/복원 유지. 가림 이미지는 미리보기에서도 답 확인 전 마스킹한다.
- 직접 만들기와 자료로 만들기는 카드 추가 아래에 묶고, 생성 첫 자료 및 새 카드 과목을 진입 과목에 맞춘다. 자료가 없으면 과목의 자료 업로드로 연결한다.
- 보더리스 중립 면·타이포그래피·공통 간격 토큰을 사용한다. 키보드 포커스 표시만 유지한다.
- 검색/범위/정렬을 journey state에 보관하며 복습 종료 후 진입 카드 목록으로 복귀한다. 평가, 오프라인 큐, 동기화 로직은 기존 체계를 유지한다.
