## 도메인 결정

- [Anki 공식 Deck options](https://docs.ankiweb.net/deck-options.html#fsrs): 목표 기억률이 높아지면 간격이 짧아지고 복습량이 늘어난다. 기본 90%를 기준으로 85/90/95% 프리셋을 제공한다. 기존 80~97% 개별 설정도 세부 설정에 유지한다.
- **FSRS를 ‘1·3·7일의 비율 조절’이라고 설명하지 않는다.** 일괄 1·3·7시간으로 환산하면 카드별 기억 모델과 다르다. 기존 고정 간격과 맞춤 간격은 유지하고 실제 평가 버튼에서 다음 예약 시간을 확인한다.
- 이미지 가림도 기존 카드 평가 API와 동일한 SRS 설정을 사용한다. 별도 복습 설정을 만들어 서로 어긋나게 하지 않는다.
- 카드 복습 화면에는 핵심/자세히 토글이 이미 없다. 공통 설정의 해설 길이는 문제풀이용임을 명확히 한다.
- ‘형광펜 자동 감지’는 색상 분석 기능이다. AI로 이름만 바꾸지 않는다. 별도의 이미지 기반 AI 제안은 좌표·라벨 검증 후 사용자가 적용해야 하고, 실패하면 수동 편집을 유지한다.
- AI 카드 만들기는 기존 자료 생성 기능의 이름과 진입을 분명히 한다. 사진은 기존 자료 업로드/OCR→자료 기반 카드 생성으로 이어진다. 가림 생성은 도식의 정답 영역을 찾는 별도 이미지 제안이다.

## 구현 확인

1. 기능 구현: 객체 지우개, 삭제, 50단계 undo/redo, 포인터 1회=이력 1개, 빠른 펜 스트로크 보간, AI 가림 제안 미리보기.
2. 도메인 재검토: 이미지 경계와 100개 가림 제한, FSRS 적용 시점, 기존 개인별 retention 값 보존.
3. 결함 점검: pointercancel/lostcapture는 미완성 편집 복원, 새 사진은 과거 이미지 이력 폐기, AI 제안은 자동 덮어쓰지 않음, 마우스 외 포인터/키보드 편집 제공.
4. 정리: 도구/실행 취소/선택삭제 위계 분리, 브랜딩 색상의 가림, 상태 문구와 오류를 현장에서 노출.

브라우저 시각·조작 검증은 root 통합 단계에서 수행한다. 단위/계약 테스트를 실모델의 위치 정확도 검증으로 표현하지 않는다.
