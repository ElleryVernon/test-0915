## Applied interaction contract

- My avatar and profile edit both reach photo editing. Choose a raster file, inspect the square crop as a circle, explicitly save or discard. Existing photo can be changed or removed after inline confirmation.
- 5 MB input limit; JPEG/PNG/WebP only; server signature/config/decode validation; maximum 24 million pixels; 512×512 re-encoded JPEG without EXIF. Authenticated own-only endpoint, no public object URL, no caller-supplied user key. Bootstrap adds avatarUrl only to the caller profile, never to linked children or public community profiles.
- Photos are private to My in this version; there is no silent public-avatar opt-in.
- Parent feed contains replies to their own posts and actual completed question/essay submissions or card reviews by linked children. No page-view completion events. One per parent/child/Korean calendar day, only after linking, with learning activity disclosure enabled by the student.
- Parent bootstrap revalidates a bounded seven days of actual completed activity before cached payload lookup, so coming back tomorrow still shows yesterday's work. Dates and timestamps come from the completion event. New notices and permission revocation invalidate the parent's cache; this also covers a child that is not currently selected. Unlink/privacy revocation removes existing completion disclosures. Notification click revalidates child selection before navigating.
- Read/unread is individual when opened, with an explicit mark-all action. Activities use borderless rows, category/time metadata and visible destination labels.

## Four-pass review

1. Complete implementation: photo API/storage/normalization, editor, My avatar; role-aware parent comments, deduplicated activity creation and feed.
2. Domain review: renamed activity copy to avoid falsely claiming all daily learning is complete; tied visibility to existing student activity sharing and revised its description.
3. Correctness review: copied avatar URL does not select another owner; parent notices invalidate cache before reads; pre-link activities excluded, stale links rechecked on click; per-notice reads scope to current user.
4. Polish: identical crop preview/server thumbnail, explicit save/cancel/remove labels, consistent tokens and 40px controls; root handles final integrated live UI QA.
