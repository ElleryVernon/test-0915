# Memoryz · 탭과 기능별 개선

후속 컬러 수정: 모든 그라데이션 면을 단색 #FF6F0F로 교체하고, 주황 배경 위 텍스트·아이콘 및 완료 체크를 흰색으로 통일했다. [최신 캡처](screenshots/curriculum/index.html)를 기준으로 확인한다. 아래 기능별 캡처는 변경 당시 기록이다.

2026-09-15. 기존 모바일 제품의 기능과 데이터 흐름을 유지하면서 정보 구조와 상호작용을 개선했다. 디자인 원본 HTML과 오렌지 그라데이션의 흰 글자, 중립색 뱃지, OS 불꽃 이모지는 계속 적용한다.

이미지를 실제로 확인한 후 관련된 구조만 적용했다. 당근의 밝은 버튼 영역에서 가장 많이 관측된 압축 픽셀은 RGB(255,111,14)였으며 주변 픽셀을 함께 보고 #FF6F0F로 맞췄다. 공식 토큰 API에서 추출한 값은 아니다. 흰색 텍스트와 이 밝은 주황의 단색 대비는 약 2.79:1이며 일반 텍스트 WCAG AA 4.5:1 충족으로 표시하지 않는다. 사용자의 색 선택을 적용하고, 작은 주황 텍스트에는 별도 진한 토큰을 유지한다.

시간표는 이전 카드형 UI에 시작·종료 시간과 여유 시간 추가 동작을 결합한다. 여유 시간은 겹친 일정들을 합친 뒤 계산하며, 하루의 시작·끝을 임의로 가정하지 않는다. 여유 시간 행을 누르면 범위가 채워진 폼을 열고 사용자가 수정·저장한다.

## 구현 범위

- 공통: `globals.css`, `ui.tsx`의 버튼·선택·입력·시트·목록·간격.
- 홈: 실제 당일 일정에서 현재/다음 일정 요약.
- 학습: `subjects.tsx`, `quiz.tsx`, `essay.tsx`, `cards.tsx`, `shared.tsx`.
- 시간표: `planner.tsx`의 표시 구조. 저장·충돌 검사·AI 복구 계약은 유지.
- 커뮤니티와 계정: `community.tsx`, `account.tsx`. 게시·댓글·개인정보 설정의 요청 경로는 유지.

기존 동작 및 여유 시간 계산 테스트와 프로덕션 빌드(타입 검사 포함)를 통과했다. 실제 로컬 프로덕션 브라우저에서 24개 화면을 캡처했고, 360·390·430px 측정에 가로 넘침이 없었다. 최종 브라우저 콘솔 오류·경고는 없었다. 문제 풀이의 뒤로 가기는 설정 화면으로 복귀하도록 수정했고, 홈·학습·마이의 오답 개수는 최근 시도 기준으로 통일했다.

여유 시간 CTA의 날짜·시간 자동 입력, 직접 수정, 취소와 다른 구간 열기를 확인했다. 카드 앞·뒤 전환, 문제 선택, 필터, 작성 폼 비활성/활성 및 초안 유지도 확인했다. 이번 화면 검증에서는 일정 저장·게시·채점·외부 AI 생성을 제출하지 않았다. 외부 서비스 배포나 실제 기기 검증으로 해석하지 않는다.
