## 레퍼런스 확인

Mobbin MCP의 실제 이미지 **15개**를 확인했다. 커뮤니티 11개, Instagram DM 4개다. 별도로 반환된 Instagram 위젯 화면 1개는 목적이 달라 비교 수에서 제외했다. Blind와 Everytime 이름으로 검색한 Mobbin 결과에는 해당 앱 화면이 나오지 않아 유사 결과를 해당 앱으로 표기하지 않았다.

## 적용 흐름

- 커뮤니티 첫 화면은 전체 글. 제목 → 본문 미리보기 → 분류/첨부 → 작성자·시각/공감·댓글 순서로 읽는다. 카테고리는 가로 필터, 학교 정보와 정렬은 공통 높이의 도구 행이다. 팔로잉은 직접 선택할 때 글과 카드를 보여준다.
- 상단 공간 이름은 전체 커뮤니티·학교 커뮤니티·쪽지. 검색은 내정보 바로 왼쪽에 유지한다. 목록에서 글을 열었다 돌아오면 원래 필터·검색·스크롤을 복원한다.
- 글쓰기는 닫기·제목·등록의 헤더, 게시 공간·익명·게시판, 제목·본문, 첨부 순서다. 사진·문제·카드·자료를 하단 도구에서 바로 고르고 나머지는 더보기로 연다. 현재 선택한 게시판이 새 글에 반영된다.
- 첨부 초안은 문제 제목과 가림 상태를 먼저 보여주고 자세한 내용은 펼쳐 확인한다. 학습 블록 바깥 테두리를 없애고, 풀어보기·정답 보기·카드 담기 같은 실제 행동은 44px 이상 버튼으로 구분한다. 최대 개수, 사진 검사, 원본 소유권 확인, 학습 화면 복귀를 유지한다.
- 쪽지함은 상대·미리보기·시각·안 읽은 상태를 보여준다. 대화를 열면 전용 헤더와 메시지 흐름, 화면 아래 입력 바를 쓴다. 메시지를 읽는 중 새 메시지가 와도 읽던 위치를 강제로 바꾸지 않는다.
- 답장 인용·원문 이동·공감·내 메시지 전송 취소, 날짜/연속 메시지 묶음, 이전 메시지 불러오기, 전송 중/실패/재시도를 제공한다. 실패한 요청은 최초 요청 식별자와 내용을 보존하며 자동으로 다시 보내지 않는다.
- 쪽지에서도 문제·카드·자료·사진 등 기존 학습 블록을 최대 3개 공유한다. 상대는 공유된 문제를 풀거나 오답노트·카드 보관함·시간표로 가져갈 수 있다. 학부모/학생과 차단 경계를 유지한다. 비공개 대화에서 복사한 카드는 자동 공개하지 않는다.
- 읽음은 보이는 대화에서 화면에 들어온 메시지까지 명시적으로 기록한다. 온라인·입력 중처럼 서버가 알 수 없는 상태를 표시하지 않는다. 대화 갱신은 화면이 활성일 때 6초 간격으로 이루어진다.

## 검증

- 전체 프런트엔드 테스트, TypeScript 검사, 프로덕션 빌드 통과. `PRECOMPRESS_OK files=109`. DM 전용 프런트엔드 12개 검사와 실제 격리 DB를 사용하는 백엔드 DM 7개 검사, 전체 Go 테스트를 독립적으로 재실행했다.
- 실제 브라우저에서 격리 계정으로 학교/전체 전환 → 질문 분류 → 제목·본문 입력 → 문제 첨부 → 닫기/초안 복원 → 등록 → 상세 → 댓글 등록 → 원래 학교·질문 목록 복귀를 확인했다. 검색은 내정보 바로 왼쪽이다.
- 쪽지 새 대화 진입, 안 읽은 대화, 인용 답장, 읽음, 하트, 확인 후 보내기 취소, 문제 공유·채점, 카드 공유·뒤집기·내 카드 저장, 초안과 목록 복귀를 확인했다. 상대의 읽음·응답은 격리 서버 API에서 실행하고 브라우저 반영을 확인했다.
- 격리 API만 실제 중단한 상태에서 전송 실패를 만들었다. 원래 내용과 요청 식별자가 남았고, 서버 복구 후 사용자가 재시도했을 때 DB에 메시지가 한 번만 저장됐다. 자동 재전송은 없다.
- 320px/390px 반응형 프레임에서 실제 앱 빌드를 조작했다. 목록의 `clientWidth`와 `scrollWidth`가 모두 320px였으며, 쪽지 입력창은 폭 변경에 따라 90px → 68px로 다시 계산되고 `clientHeight`와 `scrollHeight`가 일치했다. 520px의 짧은 화면과 844px 높이를 확인했다. iOS/Android 실기기의 소프트 키보드는 이번 검증에 포함하지 않았다.
- 브라우저 검사에서 발견한 초안 이전 누락, 쪽지 첨부 개수 오안내(5 → 3), 화면 폭 변경 시 입력 잘림, 공유 버튼의 공통 스타일 누락, 쪽지 풀이의 커뮤니티 전용 안내 문구를 수정했다.
- 전용 로컬 DB(`127.0.0.1:15444/memoryz`)의 스키마를 9 → 10으로 올리고, 해당 프로젝트의 8080 API만 재시작했다. 3000 화면에서 기존 커뮤니티 글과 기존 쪽지 목록이 정상 로딩되는 것을 확인했다. 글·댓글·쪽지 전송 검증은 별도 임시 DB에서만 진행했다.

범위: 인스타그램의 목록·대화·답장·공감·읽음·복구 흐름을 참고한 학습 DM이다. 음성/영상 통화와 입력 중 표시는 포함하지 않는다. 대화는 활성 화면에서 6초, 쪽지함은 12초 간격으로 새 내용을 확인한다. HTML은 소스로 분석했고 Mobbin 이미지는 직접 확인했다. 완료 게이트는 9개 충족, 미충족 0개, 제외 0개다.
