## 상태와 다음 행동

- 자료·학습 콘텐츠 없음: 첫 자료 추가 → 과목이 없으면 과목 생성 → 자료 입력. 과목이 하나면 바로 자료 입력, 여러 개면 과목 선택. 자동 생성은 수행하지 않는다.
- 자료만 있고 본문이 모두 20자 미만: 자료 내용 보완 또는 새 자료 추가. 생성 가능한 것처럼 안내하지 않는다.
- 사용 가능한 자료 있음, 학습 콘텐츠 없음: 플래시카드·서술형·객관식 만들기. 기존 자료 선택 → 설정 → 생성 공통 작업창을 재사용한다.
- 카드·문제·서술형 중 하나라도 있음: 기존 학습 2×2 메뉴. 자료 없이 직접 만든 카드, 가져온 문제도 포함하며 삭제된 카드는 제외한다.
- AI 사용 불가: 저장된 자료를 유지하고 직접 카드 작성을 제공한다.
- 모든 상태에서 내 과목·자료 관리 진입을 유지한다. 첫 방문 여부 플래그 대신 실제 자료/콘텐츠로 판단하므로 재접속해도 진행 상태에 맞는다.

## 시각·상호작용 원칙

기존 간격·색상 토큰, 보더리스 면, 일관된 좌우 여백을 사용한다. 현재 단계는 글자와 완료 아이콘으로 구분한다. 첫 화면에 비어 있는 오답노트나 실행할 수 없는 학습 메뉴를 나열하지 않는다. 과목 생성 직후 자료 등록 또는 직접 카드 작성으로 이어지며, 취소 후 다시 시작하면 이미 만든 과목을 재사용한다.
