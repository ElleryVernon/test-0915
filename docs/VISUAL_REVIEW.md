# 화면 검토 기록

## 캡처에서 발견해 수정한 내용

- 복습 화면의 불필요한 하단 흰 여백을 없애고 회색 배경을 화면 끝까지 연결했습니다.
- 카드 뒷면의 긴 해설을 제목과 본문으로 나누어 읽기 쉽게 했습니다.
- 생성 중 진행 상태를 명시하고 입력과 중복 실행을 막았습니다. 성공 후 조회 실패는 다시 생성하지 않고 조회만 재시도합니다.
- 시간표에서 겹치는 일정의 이름을 저장 전에 표시합니다. 빈 날짜의 중복 추가 버튼을 정리했습니다.
- 댓글·친구 목록 조회 실패에 재시도를 제공하고 로딩과 빈 기록을 구분했습니다.
- 오프라인 재진입 시 홈 집계도 기기에 저장된 최신 복습 상태를 반영합니다.
- 원본 PDF는 브라우저 기본 iframe이 빈 화면으로 남는 것을 확인하고, 인증 파일을 읽는 PDF.js canvas 뷰어로 교체했습니다. 페이지 이동·로딩·실패 재시도와 본문 텍스트를 제공합니다.

실제 기능별 캡처는 `screenshots/`에 있습니다. `*-before.png`는 개선 전 비교용이며 나머지는 검증 시점의 실행 화면입니다. 샘플 계정만 사용했고 화면 수치들은 실제 로컬 학습 기록을 반영합니다.

추가 수정: 노란 형광펜 자동 가림이 주황 화살표까지 선택하는 문제를 색상·영역 검증으로 수정했습니다. 생성 개수를 바꾸고 새로고침할 때도 마지막 미확인 작업의 원래 개수를 복구합니다. 360px·430px 홈의 document 폭과 viewport 폭이 같아 가로 넘침이 없음을 확인했습니다.
