# 피드백 적용 현황 — 2026-09-17

현재 작업 트리와 기존 검증 기록을 대조했다. 아래의 **이번 수정·검증**과 **기존 반영**은 구분한다. 기존 반영 항목을 이번 작업에서 모든 기기·운영 환경까지 다시 검증했다는 뜻은 아니다. 실제 결제 활성화는 미완료 상태로 남긴다.

| 과목 없는 직접 카드 작성이 자료함 안내에서 끊김 | 과목 생성 의도를 전달하고 생성된 과목을 선택한 카드 편집기로 연결 | 별도 빈 계정: 과목 생성 → 카드 저장 → 한국사 보관함 1장 |

취소한 등록 의도는 URL에서 정리하여 새로고침 때 다시 열리지 않게 했다. `SourceUploadFlow`를 첫 학습·자료함·카메라 진입에서 재사용한다. 보더리스 면과 기존 간격 토큰을 유지했다.

## 이번 검증

`.unlazy/feedback-closeout/GATES.md`에 타입 검사, 학습/홈 집중 테스트, 전체 프런트엔드 테스트, 정적 배포 빌드와 브라우저 증거를 기록한다. 실제 로컬 API를 사용하는 임시 계정 2개로 확인했다. 홈·자료 등록은 390×844, 별도 카드 작성 탭은 1280×720 브라우저에서 확인했으며 가로 넘침과 콘솔 오류는 없었다. 실제 모바일 기기 카메라, 운영 결제, 운영 배포 성공은 이번 결과에 포함하지 않는다.
