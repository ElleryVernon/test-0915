# 세션 만료 공통 처리

2026-09-16

인증 API의 401은 기능별 오류/재시도 카드 대신 앱 전체의 로그아웃 경계로 처리한다. 일반 API, AI 작업 조회, 자료 본문, 파일 업로드, PDF, 학습 이미지 요청에 같은 sessionFetch를 적용했다. 로그인 거부·403·외부 URL 오류는 세션 만료로 오인하지 않는다.

만료 시 사용자 화면과 열린 시트를 즉시 내리고 사용자 본문 메모리·세션 스냅샷·학습 조회 캐시를 정리한다. 서버 로그아웃으로 HttpOnly 쿠키를 해제하며, 연결이 지연돼도 2.2초 안에 루트 로그인 화면으로 이동한다. 로컬 무효화 표시가 남아 있으면 과거 스냅샷을 복원하지 않는다. 사용자가 작성한 초안과 미전송 복습 기록/작업 식별자는 계정별로 보존하되 로그인 전에는 노출하지 않는다.

동시 401은 한 번만 처리한다. 늦은 응답은 이전 세션 데이터를 복원할 수 없고, 이전 로그인에서 지연된 401이 새 로그인을 종료하지 못한다. 탭 간 로그아웃은 storage 이벤트로 전달하며 브라우저 history·BFCache 복원도 재검증한다.

검증:
- 전체 프런트엔드 테스트 202개, 타입검사, production build 통과.
- 전체 Go 테스트 및 sqlc diff 통과.
- localhost:3107의 새 scratch DB에서 샘플 세션 1개를 실제 만료시키고 서버 메모리 캐시만 재시작했다. 기존 127.0.0.1:3000의 세션/데이터는 만료시키지 않았다.
- 커뮤니티 → 학교 커뮤니티 요청의 401 후 첫 탭과 별도 시간표 탭 모두 `/` 로그인 화면으로 이동. 이전 피드·메뉴·오류 재시도 버튼 없음. 뒤로 가기도 로그인 화면 유지.
- 401/403 구분, 동시 요청, 로그인 endpoint 제외, 이전 세션의 지연된 성공·401 응답을 회귀 테스트로 검증.

이전부터 열려 있던 탭은 새 번들을 받도록 한 번 새로고침해야 한다. 운영 배포와 네이티브 앱 검증은 포함하지 않는다.
