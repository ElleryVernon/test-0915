## 기획 결정

1. 오늘 복습은 실제 카드 복습으로 바로 시작한다. 학습 방법 4개는 과목 수에 밀리지 않도록 상단의 2열 바로가기로 제공한다.
2. 내 과목은 과목명순, 학기 필터는 기본 전체 학기를 명시한다. 본문 아래에서 경쟁하던 과목 추가/배운 과목 설정은 과목 관리로 모은다. 관리 안에서 공부 중 과목의 설정/추가와 이전 학습 이력을 구분한다.
3. 내 과목은 자료·문제·카드를 담는 Subject이고 배운 과목은 Profile.completedSubjects 이력이다. 데이터를 자동 병합하거나 이력 저장이 새 보관함을 만든다고 오해하게 하지 않는다. 현재 구현에 없는 AI 맞춤화 효과를 약속하지 않는다.
4. 생성 시트에는 현재 선택한 자료 제목·과목·종류·등록일·본문 미리보기와 변경 행동만 보인다. 자료 목록은 별도 선택 시트에서 검색하고 과목별로 좁힌다.
5. 최근 등록순은 createdAt 내림차순, 동률은 한국어 이름순+id순. 이름순은 숫자를 고려한다. 없는 최근 사용일/수정일을 추정하지 않는다. 진입 자료를 우선 선택하고 일반 진입은 가장 최근의 생성 가능한 자료로 시작한다.
6. 자료가 적든 많든 같은 검색/정렬 기준을 쓴다. 커뮤니티에서 저장한 자료도 임의로 숨기지 않는다. 과목·등록일·본문 미리보기로 출처 맥락을 판단할 수 있다. 제목만으로 자료 출처를 추측하거나 학습 데이터를 제외하지 않는다.
7. 본문 20자 미만은 선택할 수 없는 이유를 표시한다. 작업 중/복구 중에는 자료 변경을 잠그고 불확실한 요청을 자동 재전송하지 않는다.
8. 완료 상태에서는 자료 선택/개수 설정을 감추고 저장한 결과와 다음 행동을 보여준다. 결과 버튼은 새 생성을 하지 않고 목록 갱신 후 해당 자료로 이동한다. 닫힌 미확인 완료 작업은 기존 복구 체계로 다시 확인한다.
9. 공통 간격 토큰, 회색 면과 글자 위계, 44px 이상 조작 면적을 사용한다. 장식 테두리를 추가하지 않고 키보드 포커스 표시는 유지한다.
