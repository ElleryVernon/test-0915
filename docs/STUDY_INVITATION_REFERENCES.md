## 적용할 구조

- 부드러운 브랜드 주황 계열의 큰 보더리스 영역. 단순한 종이·카드 일러스트, 두 줄 제목, 부담 없는 짧은 설명.
- 중단한 학습은 서술형·문제풀이·카드 복습을 합쳐 실제 활동 시각 순으로 정렬한다. 가장 최근 학습을 앞에 두고 다른 학습은 인라인 목록으로 펼친다. 자동 슬라이드나 기능별 임의 우선순위는 사용하지 않는다.
- 중단한 학습이 없으면 복습 예정 카드 한 장 → 새 문제 한 개 → 새 서술형 → 기존 학습 다시 보기 순서로 작은 시작을 제안한다. 반복 호출 때 임의로 섞지 않는다.
- 실제 과목·학습 내용을 미리 보여주고 ‘이어서 쓰기’, ‘한 장 복습하기’, ‘한 문제 풀기’처럼 정확한 행동을 둔다. 버튼 하나만 시각적으로 강조한다.
- 작성 중 답안은 문제 버전과 마지막 제출 시간을 확인한다. 삭제·변경·완료된 학습을 ‘작성 중’으로 제안하지 않는다.
- 2×2 학습 방법과 내 과목·자료는 유지한다. 신규 계정/자료만 있는 계정은 기존 온보딩을 유지한다.
- 수치 조작, 미구현 출석 보상, 자동 AI 호출, 출처 없는 예상 시간, 추천 캐러셀은 넣지 않는다.
- 큰 화면에서만 예쁜 구조가 되지 않도록 320/390px와 데스크톱에서 확인한다. 탭·포커스·뒤로가기·긴 문제명을 확인한다.

## 상태별 동작

| 상태 | 상단의 행동 |
|---|---|
| 자료·학습이 전혀 없음 | 기존 예제/첫 자료 온보딩 유지 |
| 자료만 있음 | 기존 첫 문제·서술형·카드 만들기 안내 유지 |
| 학습 콘텐츠는 있지만 시작 전 | 복습 카드 한 장 또는 새 문제 하나 제안 |
| 내용 없는 서술형을 열었다 닫음 | 작성 중으로 세지 않음. 하단 학습 메뉴의 개수도 동일 기준 |
| 서술형 초안 1개 | 해당 답안의 작성 글자 수 또는 키워드 진행 표시, 그 문제로 이동 |
| 객관식 진행 중 | 문제 순서·선택 답·저장된 피드백·풀이 기록 복원 |
| 객관식 저장 응답이 불확실함 | 저장 확인 필요를 표시하고 기존 요청 식별자로 재시도 가능 |
| 카드 복습 중 | 복습 순서·현재 카드·앞뒷면·이전 평가 기록 복원 |
| 여러 기능 또는 여러 서술형 중단 | 최근 활동을 먼저, 나머지는 펼친 목록에서 직접 선택 |
| 문제 마지막 피드백 확인 중 | 아직 해설을 확인할 수 있도록 유지; 결과 화면까지 마치면 제거 |
| 문제/카드 완료 | 그 세션만 제거하고 다른 초안은 유지 |
| 기존 내용이 변경·삭제됨 | 오래된 상태를 그대로 주입하지 않음. 유효한 학습을 새로 선택하도록 안내 |
| 다른 탭에서 현재 문제·카드 완료 | 저장된 진행과 서버 상태를 대조해 오래된 이어하기 제외 |
| 오래된 중단 상태 | 재시작을 압박하지 않는 문구, 최근 활동 뒤로 정렬 |
| 오늘 공부했고 새로운 문제도 남지 않음 | 완료를 인정하고 쉬어도 된다는 안내와 선택적인 재학습 |
| 저장소 제한/손상 | 학습 화면을 막지 않음; 저장을 읽을 수 없는 항목은 추천하지 않음 |

진행 저장은 로그인 사용자별 브라우저 로컬 저장소이다. 계정 간 섞이지 않으며 새로고침 뒤 복원된다. 기기 간 미제출 답안 동기화를 구현했다고 주장하지 않는다. 단순히 자료에 미풀이 문제가 있다는 이유로 실제 시작하지 않은 세션을 ‘중단함’으로 만들지 않는다.

## 검증

격리된 로컬 계정으로 서술형 35자 작성 → 객관식 1/2 완료 → 카드 1/2 복습·뒷면 확인 → 학습 허브 복귀 → 새로고침 → 각각 재개를 실제 브라우저로 확인했다. 문제 선택과 카드 뒷면이 복원됐고, 끝낸 문제풀이와 카드 복습만 목록에서 사라졌다. 320px/390px에서 가로 넘침 없음, 키보드 Tab 포커스와 Enter 재개 확인. 신규 온보딩, 변경·삭제·타 계정·저장 실패 등은 회귀 테스트로 확인한다.
