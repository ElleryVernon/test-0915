# 고등학교 배운 과목 목록

2026-09-15. `src/lib/curriculum.ts`를 기준으로, 2022 개정 보통 교과 155개(기본수학·기본영어 포함), 2015 개정 보통 교과 104개를 제공한다. 목록의 과목명은 경기도교육청 2026 자료집의 원문과 대조했다. 국가 보통 교과 목록과 특정 학교의 실제 편제표는 구분한다.

## 목록과 학년의 관계

- 현재 학년과 서울 시간 기준 학년도(3월 시작)로 입학 학년도를 추정한다. 2025학년도 이후 입학이면 2022, 이전이면 2015를 기본 표시한다. 2026학년도에는 고1·고2=2022, 고3=2015다.
- 학년 선택은 목록 탐색 기준이다. 프로필 학년을 자동 변경하지 않는다. 졸업·기타는 적용 교육과정을 단정하지 않고 직접 고를 수 있게 한다.
- 공통 과목은 주로 고1, 선택 과목은 고2·고3 중심으로 안내한다. 선택 과목을 특정 학년이나 학기에 고정 배정하지 않는다. 체육·예술·정보 등 선택 과목은 학교에 따라 고1에도 편성한다.
- 2022의 기본수학1·2, 기본영어1·2는 공통수학·영어 대체 이수 가능 과목으로 표시한다. 2015 기본 수학·기본 영어는 표에 따라 진로 선택으로 분류한다.
- 전문 교과, 특수목적고 전용 계열 과목, 지역·학교 승인 과목의 전체 목록은 포함하지 않는다. 학교 과목 직접 추가로 실제 이수 과목을 이름 그대로 선택할 수 있다. 경기도 승인 교양 과목을 전국 공통 목록으로 섞지 않는다.

## 선택과 저장

공통/선택 및 교과 영역별 탐색, 전체 과목명 검색, 선택 과목 확인 시트를 제공한다. 검색은 공백·가운뎃점·로마 숫자를 정규화해 `생명과학 2`로 `생명과학Ⅱ`를 찾을 수 있다. 검색 시 현재 교과 필터와 공통/선택 구분을 넘어 현재 교육과정 전체에서 찾는다.

교육과정·학년·필터를 바꿔도 선택은 유지한다. 기존 `통합과학`, `통합사회`, `공통수학` 같은 이름을 쪼개거나 자동 치환하지 않는다. 선택한 과목 확인에서 원래 이름 그대로 확인·해제한다. 직접 추가도 저장 버튼을 누르기 전까지 작성 중인 선택에만 반영한다. 기존 `PATCH /api/profile`의 `completedSubjects: string[]`, 과목명 60자 및 총 100개 제한을 유지한다.

## 함께 반영한 색상 수정

사용자 후속 지시에 따라 기존 `.gradient-surface`를 `.primary-surface`로 교체했다. 홈·복습·기록·응원·생성 상태·로그인의 주황 면은 단색 #FF6F0F이고, 해당 면 위 텍스트·아이콘은 `--on-primary: #FFF`다. 흰색 버튼과 로그인 입력 패널처럼 배경이 별도로 있는 자식은 그 배경에 맞는 콘텐츠 색을 사용한다. 홈 주간 완료 체크와 카드 가림 표시의 검은 아이콘을 흰색으로 수정했다.

## 검증

학년도 경계, 적용 학년, 개정 전후 과목명·종류, 검색 범위, 기존 이름 보존 및 선택 한도 테스트와 전체 기존 테스트, 프로덕션 빌드를 통과했다. 모바일 브라우저의 실제 동작·색상 측정·캡처는 [검증 갤러리](screenshots/curriculum/index.html)와 [.unlazy/curriculum/GATES.md](../.unlazy/curriculum/GATES.md)에 기록한다. 실제 모바일 브라우저에서 교육과정 전환, 검색, 선택 보존, 직접 추가, 홈·마이·복습 답면 색상을 확인했다. 360px 화면에서 문서와 선택 시트 너비는 모두 360px이며, 브라우저 경고·오류 기록은 없었다. 기존 프로필 저장, 카드 평가 및 외부 AI 요청은 실행하지 않았다.
