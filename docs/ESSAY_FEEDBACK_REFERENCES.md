## 적용 원칙

- 키워드 확인 전에는 정답 상태를 숨기고 확인 후 정답·오답·놓친 정답을 색/아이콘/글자로 동시에 표시한다. 결과 확인 후 다음 단계로 직접 이동한다.
- 다음 단계로 넘어가기 / 이전 단계로 돌아가기 표기를 일관되게 유지한다. 제출·재시도는 이동과 다른 이름을 쓴다.
- 예시, 지난 답안, 내가 쓴 답안, 코칭을 원문 문장/문단 경계로 나눈다. 문장을 임의로 요약하거나 삭제하지 않는다.
- 작성 중 힌트와 채점 후 구조도에서 같은 컴포넌트를 사용한다. 노드는 예시 답안 원문 문장과 일치한 키워드다. 화살표는 설명 순서임을 밝힌다.


## 구현 및 검토 기록

- 1차 구현: 5개 키워드 상태, 체크 후 재선택/진행, 단계 이동 문구, 원문 단위 문단, 공용 구조도 구현.
- 2차 도메인 검토: 다른 글 순서를 오답 처리하지 않으며 구조도를 유일한 정답/인과관계로 표시하지 않음. 원문이 없으면 실제 자료 근거로 대체하고 둘 다 없으면 빈 상태로 표시.
- 3차 결함 점검: 체크 전 정답 노출 방지, 정오 상태에서 선택 잠금, 최대 선택 개수, 소수점 문장 경계, HTML escaping, 키워드 중복 및 근거 부재 테스트. 순서 선택의 선택 상태 표시 복구.
- 4차 다듬기: 영상의 ‘바로 답안 작성하기’ 의도 반영, 최초 목록 ‘서술형 도우미’ 명칭/내 과목 관리 진입 연결, 장식 테두리 없이 상태 배경+텍스트+아이콘 사용. 집중 테스트 20개 통과. 브라우저 상호작용 검증은 root 통합 게이트에서 수행.

## 통합 확인 경로

`/essay?essay=demo-essay1` → 키워드부터 연습 → 오답 포함해 정해진 수 선택 → 확인 → 오답/놓친 정답 라벨 확인 → 다시 고르기 → 정답 확인 후 다음 → 순서/예시 → 답안 작성의 힌트 보기. 채점 결과의 서술형 구조도 보기도 같은 컴포넌트다. 유료 AI 호출 없이 구조도를 표시한다.
