# 커뮤니티 v3 구현·UX 검토

2026-09-16. 첨부된 `Memoryz 커뮤니티 리뷰 v3.html`의 피드·작성·첨부·학습 연결·프로필 설계를 기준으로 구현했다. 외부 Claude 링크는 열리지 않아 첨부 HTML의 실제 화면 정의와 정책을 읽었다. 문서의 자동 전송·자동 감지 제안은 사용자 승인이나 구현된 기능으로 취급하지 않았다.

## 첨부의 실제 동작

- 문제: 원본 소유권을 확인한 스냅샷, 정답 가림·내 답·직접 풀이. 한 사람의 최초 풀이만 집계하며 개인 Attempt를 만들지 않는다. 틀린 문제는 명시적으로 오답노트에 복사할 수 있다.
- 카드: 앞뒤·가림·이미지·다이어그램을 보존하며 내 보관함 AGAIN으로 중복 없이 복사한다. 댓글 카드의 기여도는 댓글 작성자에게 돌아간다.
- 자료: 본인 자료의 연속된 최대 3문장·2,000자 발췌. 타인은 인용만 보고 원본은 소유자만 연다. 소수점을 문장 끝으로 세지 않는다.
- 사진: 실제 이미지 검증·용량 제한·압축, 자르기와 직접 가리기. 개인 업로드 URL을 그대로 공개하지 않는다.
- 서술형: 본인 제출 답안과 일치하는 실제 점수, 피드백 댓글 진입.
- 투표: 2~4개 선택지, 게시 후 24시간, 1인 1표, 투표/마감 뒤 결과. 학부모도 자신의 게시판에서 사용 가능.
- 시간표: 본인 일정, 고정 이름 익명화, 선택 날짜로 자율 일정만 가져오기. 고정·중복·충돌은 제외하고 결과 수를 알린다.
- 수식: 기호 입력과 텍스트 수식 블록·복사. 현재 화면에 LaTeX 명령 변환 미지원 안내가 있다.

원본 자료를 삭제하거나 수정해도 이미 공유된 첨부 스냅샷은 유지한다. 본문 수정·게시 재시도에서도 원본을 다시 요구하지 않는다. 게시글 소프트 삭제는 기존에 담은 카드와 지급한 포인트를 되돌리지 않는다.

## 시트와 달리 적용한 판단·아직 없는 기능

- 자동 오프라인 전송은 하지 않는다. 사용자가 내용을 확인하고 다시 올리며 requestId로 중복을 막는다.
- 개인정보·얼굴·형광펜 자동 감지 및 한국어 이름 패턴 검사는 구현하지 않았다. 직접 가리기와 게시 전 안내만 제공한다.
- 시간표 AI 자동 재배치는 하지 않는다. 선택 날짜·시간을 유지하고 충돌을 제외해 예측 가능하게 처리한다.
- 첫 답변·채택 인앱 알림만 실제 구현했다. 21시 팔로잉 묶음, 7일 채택 요청, 외부 푸시 예약 전송은 아직 없다.
- 학교 접근은 프로필에 등록한 학교 기준이며 학교 인증을 뜻하지 않는다.
- 닉네임 30일 변경 제한·이전 닉네임 7일 표시, 신고 누적 자동 숨김/탈퇴 30일 처리, 비로그인 공유 랜딩, 학습 읽기 시간 기반 추천, 수식 LaTeX 렌더링은 이번 변경에 포함되지 않았다. 현재 계정·신고·로그인 정책을 유지한다.
- 해설에서 선택한 도식 노드의 강조와 카드 질문의 자료 자동 발췌는 자동 전송하지 않는다. 현재 문제/카드 스냅샷을 첨부하고 사용자가 자료를 추가한다.

## 검증 근거

- 전체 프런트엔드 테스트, TypeScript, 정적 production build 및 압축 성공.
- 전체 Go 테스트·sqlc diff·Go 빌드·Prisma schema validate 성공. 커뮤니티 신규 5개 + 기존 공간 격리 2개 통합 테스트는 별도 scratch DB를 사용.
- 블록 13개, 프로필 7개 및 초안 TTL/계정·출처 분리/저장소 오류/아이콘 오발송 회귀 테스트.
- 브라우저: 390×844에서 게시글 작성→문제 첨부→초안 저장/복원→게시→댓글 첨부 취소→댓글 전송→답변 채택→문제 풀이→오답노트 담기→답변자 프로필/팔로우를 직접 조작.
- 실제 해설에서 질문 게시→같은 학습 URL·같은 해설 단계 복귀→연결 질문 시트→닫기 복귀 확인.
- 전체/학교 헤더·필터와 공개 설정 화면 확인. 320px 피드 가로 폭 320 / scrollWidth 320 확인. 첨부 목록의 grid 행을 내용 높이에 맞춰 긴 문제의 줄 겹침을 수정하고 실제 캡처로 확인.
- 쓰기 검증은 외부 연결 없는 `127.0.0.1:3107`의 새 QA DB·샘플 계정에서만 수행. 기존 사용자에게 글·댓글·쪽지를 보내지 않았다. 확인 후 QA 서버·DB를 제거하고 테스트 탭과 viewport를 정리했다. QA DB readback: 보상 1건, 커뮤니티 풀이 1건, 오답노트 복사 1건, 해설 출처 질문 1건.
- 로컬 `127.0.0.1:3000`에는 additive migration 8과 빌드 결과를 적용. 운영 배포나 외부 알림 전달 검증은 수행하지 않았다.

상세 API와 보안 경계는 `server/COMMUNITY_V3.md`, 실행 게이트는 `.unlazy/community-v3/`에 기록했다.
