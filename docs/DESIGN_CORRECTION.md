# 흰 텍스트와 뱃지 복원 · 2026-09-15

사용자 지시: 그라데이션 위의 흰 텍스트를 유지하며 가시성을 개선하고, 뱃지 형태를 유지하되 색상 틴트를 제거한다. 불꽃은 OS 이모지를 사용한다.

- 홈·정답 카드·마이·생성 안내 등 공통 그라데이션 위의 텍스트를 흰색으로 복원했다. 주황·크림 곡선 위에 상단/하단 및 왼쪽 명암 레이어를 두고 약한 글자 그림자를 적용했다. 전체 접근성 대비 인증을 주장하는 변경은 아니다.
- 홈 ‘1일째’, ‘4단계’, 학습 개수, 카드 유형, 학부모 역할 뱃지를 복원했다. 색상 틴트 대신 중립적인 회색 또는 흰색 배경을 적용했다.
- 기억 배지 상세도 격자 형태로 복원했다. 획득/미획득을 명도와 설명으로 구분한다.
- 불꽃은 네이티브 문자 `🔥`로 표시한다. Apple Color Emoji / Segoe UI Emoji / Noto Color Emoji 순서로 시스템 폰트를 사용하며 이미지나 선 아이콘으로 대체하지 않는다.
- 홈의 복습 시작 버튼은 흰색 알약 형태로 복원했다. 기존 탐색 버그 수정은 유지한다.
