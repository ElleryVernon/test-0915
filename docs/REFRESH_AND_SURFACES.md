# 갱신과 인터랙션 표면 기준

## 갱신 정책

문서 자체를 새로고침하지 않고 현재 화면의 읽기 요청만 실행한다. 배경 탭, 네트워크 오프라인, 열린 대화상자에서는 주기 요청을 쉬고 복귀 시 확인한다. 요청 중복 방지, 화면 이탈 취소, 실패 시 지수 대기 및 서버 Retry-After를 공통 RefreshLoop에서 관리한다. 실패한 전송은 자동 재전송하지 않는다.

| 화면 | 자동 확인 | 사용자 제어 및 상태 보존 |
| --- | --- | --- |
| 쪽지 대화 | 4초 | 읽던 위치 유지, 하단을 보고 있을 때만 최신으로 이동. 작성/첨부 초안 유지. 오류에만 다시 연결 |
| 댓글 | 6초 | 화면에 보이는 댓글 기준 스크롤 유지. 답글 대상/정렬/작성 내용 유지 |
| 쪽지 목록 | 12초 | 당겨서 갱신, 검색어 유지 |
| 커뮤니티 글 | 15초 | 댓글은 별도 6초. 입력/첨부 상태 유지 |
| 커뮤니티 목록 | 30초 | 자동 결과는 ‘새 소식 보기’로 반영 시점 선택. 당겨서 갱신하면 즉시 반영 |
| 알림 | 15초 | 당겨서 갱신, 개별 읽음 동작 유지 |
| 홈·학습·시간표·자녀 현황 | 30초 | 입력 중에는 자동 확인 중지. 시트 및 선택 날짜 유지 |
| 공개 프로필·팔로우 목록 | 60초 | 읽기 데이터만 갱신. 개인정보 수정 폼 제외 |
| 자료·오답 목록·검색·내 정보 | 수동 | 상단 당기기 또는 키보드로 접근하는 ‘이 화면 새로고침’ |
| 문제 풀이·서술형 답안·복습 카드·카드 작성·설정 | 제외 | 학습 진행/작성 중 응답 교체 방지. 기존 채점 작업 상태 확인 유지 |

실제 전송 방식은 전경 폴링이다. WebSocket/SSE 푸시로 표현하지 않는다. 직접 요청 실패에는 다시 시도/연결을 남긴다. 당김은 최상단에서만 시작하며 입력·버튼·중첩 스크롤·열린 시트는 제외한다. 위로/가로/짧은 이동과 touchcancel은 실행하지 않는다. 완료·오류는 상태 영역으로 알리고 키보드 대체 동작을 제공한다. 앱 안에서는 브라우저 문서 재로드 제스처를 억제하며, 학습 화면에는 별도의 당김 동작을 붙이지 않는다. 이 제스처가 설치형 앱의 OS 동작과 동일하다는 의미는 아니다.

참고: [MDN Page Visibility](https://developer.mozilla.org/en-US/docs/Web/API/Page_Visibility_API), [MDN overscroll-behavior](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/overscroll-behavior).

## 공통 표면 계약과 소스 점검

- `--surface-muted`는 정보 패널, `--surface-raised`와 `--surface-sheet`는 흰 인터랙션 면이다. 기존 `--surface`의 회색 별칭을 시트 바탕에 쓰지 않는다.
- `--control-fill`은 일반 바탕에서 회색, `.bg-surface`, `.bg-canvas`, `.panel`, `[data-surface=muted]` 안에서는 흰색을 상속한다.
- `.btn-secondary`와 `.field`는 장식 테두리를 추가하지 않는다. 부모 면과 다른 밝기의 채움으로 구분한다. 비활성은 흐린 텍스트와 비활성 의미를 유지한다. 위험 버튼은 삭제 확인 단계에서만 강조한다.
- 아이콘 행/텍스트 링크/탭은 역할에 맞는 아이콘, 밑줄, 선택 선을 사용한다. 모든 링크를 채워진 버튼으로 만들지 않는다. 읽기 정보인 배지에는 클릭 경계를 추가하지 않는다.
- 버튼의 상태 색상은 `src/app/action-system.css`에서 관리한다. `--action-fill`과 `--action-text`를 한 쌍으로 지정하며, 개별 화면에서 배경만 덮어쓰지 않는다. 주요 동작은 브랜드 채움, 첨부 안의 주요 동작은 중립색 채움, 보조 동작은 부모 면과 구분되는 채움, 낮은 우선순위 동작은 항상 밑줄이 있는 텍스트로 표현한다.
- 기존 `outline` / `control-outline` 이름은 호환용이며 보더리스 보조 버튼으로 렌더링한다. 강조가 필요한 구성은 `neutral` / `control-neutral`을 사용한다. `ghost`는 기본·호버 모두 투명하게 유지하며 호버 때 새 버튼 면이 생기지 않는다.
- 호버는 포인터 기기에만 적용하고, 선택된 버튼은 같은 전경색을 유지한다. 비활성 버튼은 호버·누름에 반응하지 않으며 키보드 포커스 링은 활성 동작에 유지한다. 목록 행과 아이콘의 호버 피드백은 기본 상태의 아이콘·화살표·레이블을 보완하는 용도로 남긴다.
- Disclosure의 요약 행은 최소 터치 높이·화살표·키보드 포커스를 제공한다. 펼친 본문과 요약의 글자 굵기와 간격을 구분하고 점수는 보조 정보로 둔다.
- `src/components`의 Button/field/Sheet 사용처, CSS 모듈의 surface/background/border, `<details>/<summary>`와 상시 새로고침/타이머를 검색했다.
- 학습: 자료 메뉴, 지난 답안·코칭, 해설 선택 노드, 오답 피드백, 복습 카드 검토. 공통 버튼/필드의 부모 배경별 채움 수정.
- 소셜: 첨부 시트의 회색 별칭 오류 수정. 검색/댓글 수정/작성/과목 검색/닉네임 입력은 기존의 보더리스 톤을 유지.
- 공통 선택기: 라디오·체크박스·버튼형 pill의 기존 표현을 유지. 선택 상태는 채움/체크/선으로 구분.
- 시간표·계정·학부모: 공통 필드/버튼을 통해 반영. 자녀 통계는 자동 갱신마다 지우지 않고 자녀 변경 시에만 초기화.

검증 결과와 실제 브라우저 제약은 `.unlazy/live-refresh/GATES.md` 및 `evidence.md`에서 별도로 기록한다.
