## 구현 계약

- 신규 학생 홈과 학습 탭은 공통 시작 컴포넌트를 사용한다. 복습 0장, 빈 주간 지표, 빈 일정 안내를 첫 화면에 쌓지 않는다.
- 짧은 예제 자료가 보이는 시작 화면에서 ‘예제로 1분 학습하기’를 누른 경우에만 개인 계정에 예제 자료/문제/카드를 준비한다. 로그인 자체로 자료를 강제 삽입하지 않는다.
- 자료 읽기 → 문제 1개 풀기(선택 후 명시적 정답 확인, 틀린 답과 정답/근거 표시) → 카드 1장 복습(답 먼저 공개한 뒤 자기 평가) → 완료의 한 여정으로 연결한다.
- 서버에 기록한 실제 풀이와 복습으로 이어하기/완료를 판정한다. 다시 로그인해도 이미 끝낸 체험을 강제 반복하지 않는다. 브라우저 뒤로가기와 새로고침은 작성 중 선택과 현재 단계를 복원한다.
- 실제 자료가 있는 사용자는 기존 학습 흐름을 유지한다. 신규 사용자도 ‘내 자료로 시작하기’로 바로 업로드할 수 있다.
- 완료 후에는 예제에 묶어 두지 않고 내 자료 추가를 다음 주 행동으로 제안한다. 예제 자료는 출처가 드러나도록 표시한다.
- 기존 보더리스 시스템의 표면, 타이포그래피, 공통 여백, 포커스 표시를 사용한다. 장식만을 위한 통계·가짜 준비 진행률·자동 캐러셀은 사용하지 않는다.
