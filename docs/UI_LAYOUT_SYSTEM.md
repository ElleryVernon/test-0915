# 화면 공통 레이아웃 계약

`src/app/layout-system.css`가 간격의 단일 출처다. Tailwind의 `--spacing`도 같은 4px 단위를 참조한다. 홈, 학습, 시간표, 커뮤니티, 마이, 상세 화면, 시트 모두 이 계약을 사용한다.

| 역할 | 토큰 | 기본값 |
| --- | --- | --- |
| 화면/시트의 콘텐츠 시작선 | page-gutter | 20px |
| 카드 내부 | panel-inset | 20px |
| 작은 정보 패널 내부 | panel-inset-compact | 16px |
| 아이콘과 짧은 텍스트 | gap-inline | 8px |
| 제목과 설명, 목록 아이콘과 본문 | gap-related / row-gap | 12px |
| 같은 작업의 입력/콘텐츠 묶음 | gap-block | 16px |
| 서로 다른 작업/섹션 | gap-section | 24px |
| 페이지 헤더 높이 | header-height | 64px |
| 작은 버튼/아이콘의 터치 영역 | control-size | 44px |
| 기본 버튼/입력 높이 | control-height | 52px |

- `.page-inset`, `ScreenHeader`, `Sheet`는 같은 콘텐츠 시작선을 쓴다. 홈도 별도 40px 텍스트 열을 없애고 20px 시작선을 쓴다. 카드의 외곽과 내부 본문 시작선은 서로 다른 역할이다.
- `.layout-section`과 `.layout-group`은 부모가 `gap`을 소유한다. 자식의 위/아래 마진으로 간격을 중복 추가하지 않는다.
- `.panel`, `.list-row`, `.row-copy`, `.row-trailing`을 사용한다. 목록 구분선은 아이콘이 아닌 본문 시작선에 맞춘다.
- 읽기 영역은 정적 제목/본문/라벨로 만든다. 클릭 요소는 `Button`, `IconButton`, `.control-outline`로 경계·44px 이상 영역·포커스를 제공한다. `Button size="compact"`로 축소하고 임의 높이를 지정하지 않는다.
- `Button variant="outline"`은 원문/상세 보기처럼 부차적인 이동이다. 회색 채움은 다시 풀기 등 보조 동작, 브랜드색은 주요 진행에 쓴다.
- 기존 화면의 세밀한 간격도 공통 scale에 연결했다. 남아 있는 반 단위/광학 보정과 고정 하단 영역 보정은 수치 변경 없이 보존했다. 새 콘텐츠 레이아웃은 위 의미 토큰을 우선한다. 달력 셀/그래프/아이콘의 기하 크기, 테두리, 글자 크기는 간격 토큰과 별개다.
- CSS의 raw px 여백 및 JSX의 임의 간격 유틸리티는 `layout-system.test.ts`가 검출한다. 새 화면도 이 검증을 통과해야 한다.

## 이번 코드 리뷰에서 고친 문제

1. 해설 접기와 제목/기록이 같은 텍스트 위계여서 동작을 예측하기 어려움: 정적 헤더와 해설/다시 풀기 버튼을 분리하고 `aria-expanded`, `aria-controls`와 이름 있는 패널을 연결했다.
2. Citation과 복습 버튼 사이 간격의 소유자가 없어 두 회색 표면이 붙음: 해설 부모의 24px gap, 원문 패널 내부 16px gap으로 구조화했다.
3. 비교표의 정답 근거가 검은 주요 버튼처럼 보이고 대상명도 눌리는 상태: 대상명은 정적 행 머리글, 근거는 테두리/화살표가 있는 버튼, 정답은 텍스트 라벨로 구분했다. 확대 화면의 학습 단계에서도 대상명을 제외해 실제 근거만 이동한다.
4. 자료만 있고 열기 콜백이 없어도 원문 버튼을 표시함: 동작이 없으면 파일명만 정적으로 표시한다.
5. 페이지별 여백, 버튼 높이, 목록 보정이 독립적으로 흩어짐: 공통 토큰 및 기존 공유 컴포넌트에 연결했다. 학습 전용 간격 토큰은 별도로 만들지 않는다.

검증 범위: 로컬 브라우저 대표 화면과 학습 상호작용, 자동 회귀 검사. 운영 배포나 모든 계정/데이터 조합의 실사용 검증을 의미하지 않는다.

## 로컬 화면 검증 (2026-09-16)

- 390px 화면에서 홈·학습·시간표·커뮤니티·마이의 콘텐츠 여백 20px, 가로 넘침 없음.
- 일정 시트 여백 20px, 오늘/월 선택 및 일정 선택 칩의 높이 44px. 학교 시간 탭과 내부 달력도 조작 확인.
- 오답노트 해설 버튼 44px, 테두리와 가로 정렬 확인. Enter로 펼침/접힘, 패널 연결 확인.
- 원문 패널 내부 여백과 gap 16px, 다음 복습 버튼까지 24px. 원문 열기/복귀, 핵심/자세히, 글 해설 대체 화면 확인.
- 비교 확대는 실제 근거 4개만 이동. 저장된 가림 카드의 숨긴 내용은 점선 경계, 정적 내용에는 클릭 화살표 없음.
- 320px 오답노트에서 가로 넘침 없음.
- npm test, npm run typecheck, npm run build 통과. 운영 배포는 하지 않음.

### 홈 여백 후속 수정

홈의 44px 헤더 덮어쓰기를 제거하고 공통 `header-height` 64px를 사용한다. `home-content.page-inset` 하나가 인사말·복습·본문의 좌우 20px를 소유한다. 하위 컴포넌트의 개별 바깥 여백 계산과 홈 전용 inset 별칭은 제거했다. 일정 아이콘도 공통 `row-icon`을 사용해 목록 본문과 시작선을 맞춘다. 카드 안쪽 여백은 공통 `panel-inset`을 유지한다.

실측: 390px에서 인사말·복습·본문·응원 외곽은 모두 좌우 20px, 일정/목록 본문 시작은 56px. 390px와 320px에서 가로 넘침 없음. 홈/레이아웃 관련 검사 12개, 타입 검사, 정적 빌드 통과.
