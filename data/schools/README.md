# 대한민국 고등학교 디렉터리

2026-09-17 나이스 교육정보 개방 포털의 공개 학교기본정보 Sheet를 수집했다.
원본: https://open.neis.go.kr/portal/data/service/selectServicePage.do?infId=OPEN17020190531110010104913&infSeq=1

- `고등학교` 포함 검색 결과 2,451건을 3페이지로 모두 수집했다. 정확 일치 API의 2,409건과 차이가 나는 이유는 방송통신고등학교 42건이다.
- 국내 17개 교육청 분류 2,450건을 JSON/CSV로 제공한다. 고등학교 2,408건, 방송통신고등학교 42건이다.
- 재외한국학교교육청(V10)에 분류된 AIDT고등학교 1건은 제외 목록에 보존했다. 주소는 대구로 되어 있어 원본 분류 불일치에 해당한다. 실제 국내 학교라고 단정하지 않는다.
- 공식 학교 코드 없는 개교 예정 학교 5건은 원본과 CSV에 보존하되, 가입·커뮤니티 검색에는 제공하지 않는다. 임시 내부 ID는 공식 학교 코드가 아니다.
- 검색용 디렉터리는 2,445건이며 코드·학교명·주소를 포함한다. 동명 학교는 주소로 구분한다.
- 한국과학영재학교의 원본 도로명주소는 비어 있어 https://www.ksa.hs.kr/ 의 공식 주소로 보완하고 `addressSource`에 표시했다.
- 학교의 운영·폐교 여부를 별도로 검증한 명부가 아닌, 수집 시점 공개 목록이다. 모든 형태의 대안교육기관·특수학교 고등과정을 포함한다는 의미는 아니다.

재수집: `node scripts/collect-high-schools.mjs`
검증: `node scripts/collect-high-schools.mjs --verify`

서버는 생성된 `server/internal/schools/directory.json`을 내장하므로 사용자 검색 시 외부 API 장애나 키가 필요하지 않다.
가입 학교는 선택 사항이다. 입력했다면 검색 결과를 골라야 하며 학교 코드로 서버에서 확인한다. 미등록 계정은 학교 커뮤니티에서 검색·선택 후 등록한다. 학교 선택은 재학 인증이 아니다.
